# Gold Portfolio — PriceFix-10-CleanStatus

تطبيق سطح مكتب عربي لإدارة محفظة الذهب ومتابعة سعر الغرام.

## هذه النسخة
- سطر مختصر يعرض وقت آخر تحديث ومصدره فقط، دون عدادات أو رسائل نجاح وفشل.
- قيمة تغير السعر في صف مستقل. راجع **CLEAN_STATUS_AR.md** للتفاصيل.
- شعار Audai × Au في عنوان التطبيق وأيقونته.
- التراجع عن آخر تغيير في العمليات وتصحيح بيانات المقتنى المتبقي.
- راجع **AUDAI_AU_AR.md** لاستخدام التراجع وحدوده.
- الاحتفاظ بآخر سعر وإظهار حالته غير المحدثة مع إعادة محاولة الاتصال تلقائياً.
- علامات الشراء والبيع على المخطط، مع قراءة التاريخ والتفاصيل بالمؤشر.
- خط متوسط تكلفة الممتلكات المتبقية، مكافئ للعيار وعملة المخطط.
- اختيار نطاق تاريخي مخصص، تكبير وتصغير، وتحريك بالسحب أو الأزرار.
- تبديل المظهر الداكن/الفاتح من صفحة المخطط وتكبير خطه حتى ١٨.
- الحفاظ على ميزات الغرام فقط والعملات وخيارات الراجحي المحسوبة والخصوصية.

راجع **CHART_PLUS_AR.md** للتفاصيل والصيغ وحدود البيانات.

## التشغيل
فك الحزمة كاملة، ثم شغّل `run_app.bat` في Windows مع Python 3 مثبتاً ومكوّن Tkinter متاحاً. عند الفشل يسجل المشغل الخطأ في `startup.log`.

`requests` هو النقل المفضل مع بديل `urllib` عند غيابه. المتطلبات في `requirements.txt`، وهناك `install_requests.bat` لتثبيت النقل المفضل.

## بناء Windows EXE
شغّل `build_exe.bat`. عند نجاح البناء ينتج:
`dist/GoldPortfolio-PriceFix-10-CleanStatus.exe`.
يوجد أيضاً إعداد بناء عبر GitHub Actions.

هذه حزمة مصدر وأدوات بناء، وليست EXE جاهزاً. واجهة Windows والبناء النهائي غير مختبرين هنا.

## الاختبارات
`python -m unittest discover -s tests -p "test_*.py"`

اجتازت النسخة ١٣٢ اختبارات آلية محلية. تفاصيل التشغيل المرفقة في `tests/CLEAN_STATUS_TEST_RESULTS.txt`. لا تتطلب الاختبارات بيانات المستخدم أو اتصالاً بالشبكة.

## حماية البيانات
احتفظ بنسخة احتياطية قبل التحديث. لا تحذف ملفات الحساب ولا تُرسلها مع تقارير الخطأ. ملفات الحساب تحفظ في موقع البيانات المعتاد للتطبيق وليست ضمن هذه الحزمة.
